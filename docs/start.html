Getting started

What ReactX is, and your first app in three commands.

What is ReactX?

ReactX lets you build user interfaces the way React does — components, state and hooks — but in C++. You describe what the screen should look like; when the state changes, ReactX updates only what actually changed.

The same component code runs in two places: in the browser (compiled to WebAssembly) and in the terminal (as a text UI). No JavaScript, Node or npm is involved.

1. Install (one line)

On Linux (x86-64) one command installs everything. It downloads the reactx tool into ~/.local/bin, then reactx install downloads the compiler for the browser (Emscripten) and, if your system lacks them, CMake and Ninja into ~/.reactx — no sudo, like npm. It needs curl, git, python3, tar and xz (xz-utils on Debian/Ubuntu), which almost every Linux has.

reactx install --check shows what is there. Terminal apps also need GCC 16+ from your package manager. Other systems: the sections below or the Docker image.

Install by hand: Arch Linux

On Arch Linux, compiler and build tools can be installed via pacman in a single command:

  • GCC 16, CMake, Ninja, and Git
  • Emscripten for WebAssembly builds
  • Prebuilt reactx from GitHub Releases or build from source

Install: macOS

On macOS (Apple Silicon M1/M2/M3/M4 and Intel), tools are installed using Homebrew:

  • brew install cmake ninja git
  • GCC 16 or newer for native builds (Apple Clang can't build ReactX yet; check with g++-16 --version)
  • Emscripten for WebAssembly web apps

Install: Windows

On Windows, using WSL 2 (Windows Subsystem for Linux) is recommended for full C++26 and POSIX terminal compatibility:

  • WSL 2 gives a 100% native Linux toolchain inside Windows
  • The browser on Windows opens http://127.0.0.1:8090/ seamlessly
  • Seamless integration with VS Code (WSL extension or Dev Containers)

2. Create an app

This makes a folder with a working example: a small web app with a counter and two pages. Add --terminal for a terminal app instead.

3. Run it

reactx dev builds the app, opens a local server and rebuilds the page every time you save a file. Open http://127.0.0.1:8090/ and edit src/app.cpp.

Your first component

A component is a function: it gets its props (a struct) and returns elements. useState keeps a value between renders; changing it redraws the component.
