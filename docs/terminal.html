Terminal apps

TerminalApp, tags and Flexbox layout.

Run

TerminalApp draws your components in the terminal and handles keys until Ctrl+C.

Tags

box is a flex container, text is text that wraps, input is a text field, textarea a field of several lines (rows), button is a button. Tab and the arrows move focus, Enter or Space press.

Text fields

input and textarea edit where the cursor is: Left / Right, Home / End, Ctrl+Left / Right by words, Backspace and Delete. A textarea also takes Enter for a new line and Up / Down between lines, wraps long lines and scrolls to the cursor. Emoji and Chinese, Japanese or Korean characters take two columns, so borders and table columns stay in line; 👍🏽 or a flag is one character for the cursor and Backspace.

Layout

Flexbox, the same engine as React Native (Yoga): direction, justifyContent, alignItems, flexGrow, width and height in cells or percent, padding, margin, gap, borders.

Scrolling

What is taller than the terminal is cut off, so long lists go in a box with overflow: "scroll". In a column it is as tall as its rows, or takes the rows that are left when they don't fit; the mouse wheel and PageUp/PageDown scroll it, the focused element stays visible, a border shows the position and onScroll reports it in rows. ui::list({.children = items, .scroll = true}) scrolls inside its border. Modals and toasts use position: "fixed", so they show on the screen however tall the page is.
