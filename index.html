What's inside

all C++, no JavaScript
Hooks

useState useEffect useReducer useStore useContext — like in React.

Typed props

h(Counter, {.start = 5}): a typo in a field name is a compile error.

Two backends

Terminal (ANSI, Flexbox layout) and browser (the DOM through WebAssembly).

Router and data

Pages, links, useFetch, JSON with C++26 reflection.

C++ dev server

reactx dev rebuilds and reloads the page on every save; --proxy for your own backend.

Safe by default

Error boundaries, std::expected, contracts; every change runs sanitizers and fuzzing.

Get started

three commands

Install reactx

One line on Linux: reactx and the compiler, into your home folder, no sudo.

Create an app

A web app, or with --terminal a terminal app.

Run it

The page rebuilds and reloads every time you save.

This site is built with ReactX

The router, the components and the code highlighting — C++ compiled to WebAssembly.
