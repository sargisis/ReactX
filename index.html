What's inside

all C++, no JavaScript
Hooks

useState useEffect useReducer useStore useContext — like in React.

Typed props

h(Counter, {.start = 5}): a typo in your component's props is a compile error.

Two backends

Terminal (ANSI, Flexbox layout) and browser (the DOM through WebAssembly).

Router and data

Pages, links, useFetch, JSON with reflection.

C++ dev server

reactx dev rebuilds and reloads the page on every save; --proxy for your own backend.

Safe by default

Error boundaries, std::expected, contracts; every change runs sanitizers and fuzzing in CI · how

Where it fits

and what isn't there yet

Good for

  • A tool for a server: a terminal UI over SSH and the same screens in the browser.
  • A UI for an existing C++ library: call it directly, no bindings, no second language.
  • Internal dashboards and admin pages by a C++ team that doesn't want a JavaScript stack.

Not yet

  • Version 0.x: the API may still change before 1.0 (with a note in the changelog).
  • Native builds need GCC 16; Clang and MSVC don't build it yet. Windows: through WSL.
  • No JSX and no hydration: prerendered pages are replaced by the app, not taken over.
  • A young ecosystem: rx::ui and the docs, not thousands of npm packages.

Get started

three commands

Install reactx

Linux x86-64, one line: reactx and the compiler into your home folder, no sudo; the download's SHA-256 is checked. Read the script · macOS, Windows (WSL), Docker

Create an app

A web app, or with --terminal a terminal app.

Run it

The page rebuilds and reloads every time you save.

The router, the components and the code highlighting — C++ compiled to WebAssembly.
