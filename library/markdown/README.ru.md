# reactx::markdown

Markdown как элементы [ReactX](https://github.com/sargisis/ReactX): семантический HTML в браузере, цвета и отступы в терминале. Основы CommonMark плюс таблицы, списки задач, зачёркивание и голые ссылки из GitHub.

In English: [README.md](README.md).

```cpp
#include "rx/markdown.hpp"

rx::markdown::view({.text = "# Привет\n\nНемного **жирного** текста, `код` и [ссылка](https://example.com)."})
```

## Подключение

Библиотека идёт вместе с ReactX (с версии 1.3). Подключите её в `CMakeLists.txt` проекта:

```cmake
target_link_libraries(my_app PRIVATE reactx::markdown)
```

## Что показывает

| Markdown | Браузер | Терминал |
|---|---|---|
| `# Заголовок` … `######`, `Заголовок` + `===` | `<h1 id="…">` … `<h6>` | жирный; h1 голубой с подчёркиванием, h2 синий |
| `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` `` | `<strong>`, `<em>`, `<del>`, `<code>` | жирный, подчёркнутый, тусклый, жёлтый |
| `[текст](url)`, `<https://…>`, голая `https://…` | `<a href>` (чужие сайты — в новой вкладке) | синий с подчёркиванием, потом `(url)` |
| `![alt](src)` | `<img loading="lazy">` | `[alt]` |
| `- пункт`, `1. пункт`, вложенные, `- [x] задача` | `<ul>`, `<ol start>`, флажки | `•`, `1.`, `[x]` |
| `> цитата` | `<blockquote>` | `┃` и тусклый текст |
| ```` ```lang ```` / код с отступом | `<pre><code class="language-lang">` | зелёный, с отступом |
| таблицы с `:--`, `:-:`, `--:` | `<table>` с выравниванием | выровненные столбцы |
| `---` | `<hr>` | линия |
| два пробела или `\` в конце строки | `<br>` | новая строка |

**Безопасно для текста от пользователей:** HTML показывается как текст и никогда не выполняется, а ссылки, кроме `http`, `https`, `mailto`, `tel` и относительных (`javascript:` …), становятся простым текстом.

В браузере всё лежит в `<div class="rx-md">` с небольшим CSS (блоки кода, цитаты, таблицы), который перебивает любое ваше правило; он берёт цвет текста, поэтому работает в светлой и тёмной теме.

## Ссылки внутри приложения

По умолчанию ссылка — это `<a href>`, и `/docs` перезагружает страницу. В приложении с `rx::router` сделайте внутренние ссылки ссылками роутера:

```cpp
rx::markdown::view({.text = text, .link = [](std::string to, std::vector<Element> label) {
    return to.starts_with('/') ? router::link({.to = to, .children = std::move(label)})
                               : rx::markdown::anchor(to, std::move(label));
}})
```

`.showUrls = false` убирает `(url)` после ссылок в терминале.

## Разобранный документ

```cpp
auto doc = rx::markdown::parse(text);   // std::vector<Block>
for (auto& b : doc)
    if (b.kind == rx::markdown::Block::Kind::Heading) toc.push_back({b.id, b.level});   // оглавление
rx::markdown::plainText("**Привет** [мир](/x)");   // "Привет мир": превью, поиск
```

`Block` (абзац, заголовок с `level` и `id`, код с `language`, цитата, список с `items` и `checked`, линия, таблица с `rows` и `align`) и `Inline` (текст, курсив, жирный, зачёркнутый, код, ссылка, картинка, перенос строки) — простые структуры для своего рендера.
